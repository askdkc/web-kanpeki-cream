# 旧実装（three.js）について

移行前は `js/game.js`（three.js r158, UMD）で同じゲームを実装していた。
現行版は TypeScript + Babylon.js + Vite の構成で、`src/` 配下に置き換え済み。
移行の主な変更点は次のとおり。

- クリームの山を、判定ロジックが返す `profile`（区間ごとの密度）から直接作るようにした
- タップ単発の絞りを、押しているあいだの連続絞りへ変更（量は時間と流速に比例）
- お菓子を Blender で生成した GLB に置き換え、実寸（半径・高さ）からレーンに合わせて自動でスケール
- レーンの半幅を 1.14 に狭め、お菓子がほぼいっぱいに乗る比率へ変更

参考画像は `docs/reference/` に残している。
